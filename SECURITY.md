# Security

HashCalc CPU is a local desktop utility. Its core hashing and benchmarking functions do not require network access.

MD5 and SHA-1 are provided for compatibility and file identification. They are not recommended as collision-resistant signatures for security-sensitive use.

A matching checksum only establishes that the calculated digest matches the supplied expected digest. The trustworthiness of the expected checksum must be established separately.

For executable releases, users should obtain binaries only from the project's official GitHub Releases page.
